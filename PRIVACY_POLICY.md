# Privacy Policy for IndexedExt

**Last updated: October 15, 2026**

IndexedExt is a Chrome DevTools extension designed to inspect and manage IndexedDB databases associated with the website currently being inspected.

## Data Access and Use

IndexedExt may access database names, object stores, indexes, keys, records, and locally stored media. Access occurs only when the user opens IndexedExt in Chrome DevTools and performs an operation. This data is used exclusively to inspect and manage IndexedDB content.

## Local Processing

All database access and processing is performed locally in the user's browser. IndexedExt does not transmit IndexedDB content to the developer or to external servers.

## Data Collection

IndexedExt does not collect personal information, track browsing activity, use analytics or advertising services, sell or share user data, or use data for advertising, credit assessment, or profiling.

## Browser Permissions

IndexedExt requests only the permissions required for its DevTools database-management features. Clipboard and download access are used only after an explicit user action.

## Data Retention

IndexedExt does not retain inspected website data outside the user's browser. Local preferences and database catalog settings may be stored using Chrome's local extension storage.

## Changes to This Policy

This policy may be updated when IndexedExt functionality or privacy practices change. The latest version will always be available at its public URL.
